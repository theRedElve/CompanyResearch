# 公司调研（海外版）

> 定位：用于**海外/跨国公司**及港股、美股上市主体的快速调研，一屏看完即可用于沟通或初筛。
> 不追求尽调深度；需要行业认知与岗位匹配时，改用「公司调研（简版·偏海外）」。

用户给出任意公司名称时，输出一份结构化、可快速阅读的公司档案。

## 触发条件

用户输入中包含一个公司/机构名称，并期望了解该公司概况。典型表达：

- "介绍一下字节跳动"
- "特斯拉什么情况"
- "帮我查一下 XX 公司的营收和员工数"
- 仅发送一个公司名，无其他指令

不适用：要求做投资建议、估值分析、招聘信息、诉讼调查等超出"公司档案"范围的任务。

## 执行流程

严格按四步执行，不要跳步。

### 第 1 步：识别与消歧

1. 先把用户输入规范化为**公司全称 + 英文名 + 注册地**，不要停在简称。
2. 判断是否存在歧义，命中以下任一情况即视为有歧义：
   - 同一名称对应多个法律主体（如 "中信" → 中信集团 / 中信银行 / 中信证券）
   - 中英文同名不同实体（如 "腾讯" 与 "Tencent Music"）
   - 名称含"集团""控股""科技"等泛化词，无法唯一定位
   - 用户所在语境可能指向某个子公司而非母公司
3. **有歧义时先输出消歧段，再继续**：列出 2–3 个候选对象，每个候选给出「全称 / 注册地 / 所属行业 / 判断依据」，并说明本次采用的匹配项及理由。若无法判断，直接请用户确认，不要硬猜。
4. 无歧义则用一行 `> 匹配对象：<全称>（<英文名>，<注册地>）` 声明定位结果。

### 第 2 步：信息检索

按以下优先级取数，**不得凭记忆直接写数字**：

1. 公司官网的 About / Investor Relations / 年报（10-K、20-F、年度报告）
2. 交易所披露（SEC EDGAR、港交所、上交所/深交所、巨潮资讯）
3. 官方新闻稿、可持续发展/ESG 报告（员工人数、中国区投资常用）
4. 权威媒体或数据库（仅在前述缺失时使用，并注明媒体名与发布日期）

每项数据都要记下 **来源 + 口径 + 时间**，供第 3 步撰写使用。

### 第 3 步：交叉校验与标注

- 同一指标出现多个数值时，优先采用官方年报口径，并在备注中说明差异来源。
- 明确区分易混口径：
  - 营业额 ≠ GMV ≠ 平台交易额 ≠ 营收指引 ≠ 市值
  - 员工人数需注明是「全球」还是「中国区」，是否含派遣/外包/合资公司
  - 投资额需注明是「累计投资」「计划投资」还是「单笔投资」
- 财年与自然年不一致时必须标注（如 Apple 财年截至 9 月、Nike 截至 5 月）。
- 无法确认的项目写 **`未确定`**，并紧跟一句原因（未披露 / 口径不明 / 数据过期 / 存在冲突）。

### 第 4 步：按模板输出

见下方模板，直接复用其结构，不要自创新格式。

## 硬性规则

1. **数字必须可溯源**：每个金额、人数后附来源与时间，缺一不可。
2. **禁止臆测**：宁可写"未确定"，也不要给出估算值冒充事实。若确需给区间，标注为"估算"并说明推算方式。
3. **时效优先**：营收数据默认取最近 3 个完整财年；若最新财年尚未披露，明确写"FY2025 未披露"。
4. **单位统一**：人民币用「亿元」，美元用「亿美元」，同一表格内不混用币种。
5. **歧义不外推**：消歧未完成前，不输出任何业务或财务数据。
6. **篇幅控制**：每条业务线、每个品牌说明控制在 1 句，全篇不写背景铺陈与评论性内容。

## 输出风格

- 用表格承载对比型信息，用短句承载说明型信息。
- 不使用"众所周知""行业领先"等无信源修饰语。
- 有突出结论（如某业务占比过半）时，可在对应行后用 `**加粗**` 提示，但不额外展开分析。
